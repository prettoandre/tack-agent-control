Architecture · tack-agent-control

Control decides, the runner only executes

control owns all state and every decision. Each devbox runs one runner that exposes a closed set of five operations over herdr; it never runs a command it was sent. The highlighted path is the live terminal.

prepare: git fetch, git worktree add --no-track on run/<id>-<slug>, herdr workspace tac:<project> + tab, herdr agent start. The initial prompt goes out later, from the status poll.

stream: today control polls GET /screen (herdr pane read --format ansi) every 700 ms per open WebSocket; the spec's planned form bridges herdr agent attach through a pty.

send input: herdr agent prompt, agent send-keys, pane send-text. report state: herdr agent state, plan checkboxes (later tack wave status --json), gh pr list --head, branch HEAD. cancel: ctrl+c twice, close tab; cleanup also removes the worktree.
