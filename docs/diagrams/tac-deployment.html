Deployment · tack-agent-control

Where tack-agent-control runs

Owner devices define and watch work; the devboxes run the agents. Solid boxes run today (the e2e of 2026-10-15); dashed boxes and paths are planned.

Tailscale Serve terminates HTTPS and forwards with Host = <node>.tail39ebd.ts.net and Tailscale-User-Login; control listens on loopback only and accepts that host through TAC_PUBLIC_HOSTS.

Runner token: one per host (1Password, planned), sent as a bearer token. hosts.yaml uses the MagicDNS name, so devbox-homelab is devbox-local.tail39ebd.ts.net:7781.

Today's e2e: control on the Mac at 127.0.0.1:7780, runner on devbox-homelab with a dedicated herdr session tac-e2e. The VM and the ACL come from the infra repo (OpenTofu + Ansible).
