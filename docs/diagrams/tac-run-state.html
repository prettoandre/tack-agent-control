The life of a run

control's decide() maps the runner's facts to a state on every 5-second poll. The labels are the guards it applies.

Facts, not reports: herdr agent state, plan checkboxes, branch head, an existing PR. idle + PR also ends running or needs_attention directly; finishing and needs_attention return to running when the agent works again. A text prompt sent while blocked returns agent_blocked; answer with keys.

The idle timer starts only once the initial prompt is acknowledged (or its 3 attempts are spent), so a slow first prompt is not read as "finished". Timeout: TAC_IDLE_TIMEOUT_MS, default 15 minutes.

needs_attention still holds a host slot; retry frees the old worktree (the branch and its commits are kept), cancels the old run and queues a new run on the same branch. herdr restarting loses the pane, so the run fails; retry continues from its commits.
